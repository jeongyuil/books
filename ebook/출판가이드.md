# 『시간 위의 플랫폼』 전자책 출판 가이드

## 폴더 구조

```
ebook/
├── metadata.yaml          # 책 메타데이터 (제목, 저자, 설명)
├── epub-style.css         # ePub 스타일시트
├── build-epub.sh          # 빌드 스크립트
├── 저자소개_템플릿.md      # 저자 소개 템플릿
├── 출판가이드.md          # 이 파일
├── cover.jpg              # 표지 이미지 (추가 필요)
└── output/                # 빌드 결과물 (자동 생성)
    └── 시간_위의_플랫폼.epub
```

## Step 2: 표지 이미지 제작

### 스펙
| 항목 | 권장값 |
|------|--------|
| 비율 | 1:1.4 (세로형) |
| 최소 크기 | 600 x 840 px |
| 권장 크기 | 1600 x 2240 px |
| 형식 | JPG (RGB, 72dpi 이상) |
| 파일명 | cover.jpg |

### 무료 제작 도구
1. **Canva** (https://canva.com)
   - "Book Cover" 템플릿 검색
   - 전자책용 템플릿 다수

2. **Reedsy Cover Creator** (https://reedsy.com/book-cover-creator)
   - 무료, 전자책 특화

3. **Adobe Express** (https://express.adobe.com)
   - 무료 기본 기능

### 표지 포함 요소
- 제목: **시간 위의 플랫폼**
- 부제: 콘텐츠 플랫폼 데이터 분석가의 실전 가이드
- 저자명
- 심플한 비즈니스/데이터 관련 이미지

```bash

./build-epub.sh
```

### 빌드 결과
- 출력 파일: `output/시간_위의_플랫폼.epub`

### 문제 해결
```bash
# Pandoc 버전 확인
pandoc --version

# 수동 빌드 (디버깅용)
pandoc "../시간 위의 플랫폼.md" \
  -o "output/test.epub" \
  --toc \
  --toc-depth=2 \
  --metadata-file="metadata.yaml" \
  --css="epub-style.css"
```

## Step 4: ePub 검수

### Calibre로 미리보기
```bash
# Calibre 설치
brew install --cask calibre

# ePub 열기
open -a calibre output/시간_위의_플랫폼.epub
```

### 검수 항목
- [ ] 목차(TOC)가 제대로 생성되었는가
- [ ] 챕터 제목이 올바르게 표시되는가
- [ ] 한글 폰트가 정상적으로 렌더링되는가
- [ ] 코드 블록이 깨지지 않는가
- [ ] 테이블이 올바르게 표시되는가
- [ ] 이미지가 포함되어 있다면 제대로 보이는가

### ePub 검증 (선택)
```bash
# epubcheck 설치 (Java 필요)
brew install epubcheck

# 검증 실행
epubcheck output/시간_위의_플랫폼.epub
```

### 리디북스 (RIDI) - 추천

**URL**: https://ridibooks.com/partner

**등록 절차**:
1. 파트너 계정 생성 (개인/출판사)
2. 신규 도서 등록
3. 정보 입력:
   - 제목, 부제
   - 저자명
   - 카테고리: 경제경영 > 경영전략 또는 IT > 데이터분석
   - 책 소개 (200-500자)
   - 키워드 (5개)
4. 파일 업로드:
   - ePub 파일
   - 표지 이미지

6. 심사 제출 (1-3 영업일)
