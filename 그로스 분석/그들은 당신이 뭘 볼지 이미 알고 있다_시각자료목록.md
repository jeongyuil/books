### [그림 1] 사용자 하루 시간 지도

**Chapter**: 1
**삽입 위치**: "이용자의 하루 시간 지도" 섹션 (약 400행)
**권장 형식**: 원형 인포그래픽 (시계 형태)
**우선순위**: ★★★

**목적**: 사용자의 하루 중 콘텐츠 소비 시간대 시각화

**포함 요소**:
- 24시간 타임라인 (원형 또는 수평)
- 시간대별 활동: 출퇴근, 점심, 저녁, 취침 전
- 각 시간대의 콘텐츠 소비 패턴 (짧은 세션 vs 긴 세션)
- 경쟁 서비스 (유튜브, SNS, 게임) 표시
- 한국 vs 글로벌 비교 (선택)

**참고 키워드**: 시간 경쟁, 여가 시간, 콘텐츠 소비 패턴

### [그림 3] 리텐션 곡선 유형별 비교

**Chapter**: 3
**삽입 위치**: "리텐션이 깨지는 진짜 순간" 섹션 (약 900행)
**권장 형식**: 라인 차트 (3-4개 곡선 비교)
**우선순위**: ★★★

**목적**: 다양한 리텐션 곡선 패턴 이해

**포함 요소**:
- X축: 시간 (D1, D7, D14, D30)
- Y축: 리텐션율 (%)
- 곡선 유형:
  - **건강한 곡선**: 완만한 하락 후 안정 (녹색)
  - **위험한 곡선**: 급격한 초기 하락 (빨간색)
  - **계단형 곡선**: 한국 특유의 패턴 (파란색)
- 각 곡선의 의미 주석

**데이터 예시**:
```
D1    D7    D14   D30
100%
 │╲
 │ ╲_____ 건강한 곡선 (40% 안정)
 │  ╲
 │   ╲___ 계단형 (35% → 25%)
 │    ╲
 │     ╲_ 위험한 곡선 (15% 이하)
```

### [그림 7] 데이터 품질 5차원 모델

**Chapter**: 8
**삽입 위치**: "품질은 정확성 하나로 끝나지 않는다" 섹션 (약 2600행)
**권장 형식**: 레이더 차트 또는 펜타곤 다이어그램
**우선순위**: ★★☆

**목적**: 데이터 품질의 다차원적 이해

**포함 요소**:
```
          Accuracy
             ▲
            /│\
           / │ \
          /  │  \
Validity ◀───┼───▶ Completeness
          \  │  /
           \ │ /
            \│/
             ▼
    Consistency ─── Timeliness
```

5가지 품질 차원:
- **Accuracy** (정확성): 데이터가 실제 값과 일치하는가
- **Completeness** (완전성): 누락된 데이터가 없는가
- **Timeliness** (적시성): 데이터가 제때 도착하는가
- **Consistency** (일관성): 시스템 간 데이터가 일치하는가
- **Validity** (유효성): 데이터가 정의된 규칙을 따르는가

### [그림 8] 데이터 분석가의 4가지 역할

**Chapter**: 9
**삽입 위치**: "데이터 분석가는 어떤 역할이어야 하는가" 섹션 (약 3200행)
**권장 형식**: 4분면 다이어그램 또는 아이콘 기반 인포그래픽
**우선순위**: ★★☆

**목적**: 분석가 역할의 다면적 이해

**포함 요소**:
```
        전략적
           │
    ┌──────┼──────┐
    │ 설계자│코치  │
    │Architect│Coach│
────┼──────┼──────┼────
내부 │번역가│감시자│ 외부
    │Translator│Guardian│
    └──────┼──────┘
           │
        운영적
```

4가지 역할:
- **번역가 (Translator)**: 데이터 ↔ 비즈니스 언어 변환
- **설계자 (Architect)**: 실험/지표 설계, 구조화
- **감시자 (Guardian)**: 품질/가드레일 모니터링
- **코치 (Coach)**: 조직 역량 강화, 학습 촉진
